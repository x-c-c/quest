1. Что определяет класс? Чем обличается класс от объекта?

Класс - это шаблон, по которому создаются объекты.
## Пример класса
### Заголовочный файл `exampleClass.h`
```cpp
#pragma once
#include <string>
class exampleClass
{
private:
	int atributeOfClass_ = 10;
	std::string privateString_ = "это приватный атрибут";
	void methodOfClass(int parameterOfMethod);
public:
	std::string getPrivateAtribute();
	std::string publicString_ = "это публичный атрибут";
};

```
### exampleClass.cpp
```cpp
#include "exampleClass.h"
#include <iostream>
#include <string>
void exampleClass::methodOfClass(int parameterOfMethod)
{
	std::cout << parameterOfMethod << std::endl;
}
std::string exampleClass::getPrivateAtribute()
{
	return privateString_;
}
```
### main.cpp
```ini
#include "exampleClass.h"
#include <iostream>
#include <string>
int main()
{
    exampleClass object;
    std::cout << object.publicString_ << std::endl;		// это публичный атрибут
    std::string result = object.getPrivateAtribute();
    std::cout << result << std::endl;					// это приватный атрибут
    return 0;
}
```
2. Является ли структура классом? Чем класс отличается от структуры?
Структура является разновидностью класса, отличается тем, что в структуре все атрибуты и методы по умолчанию public, а в классе private.
Семантически структуры чаще используют как контейнер для агрегации переменных (структура данных).

4. Объясните принцип инкапсуляции.
**Инкапсуляция** — принцип ООП, при котором данные (поля) и код, работающий с ними (методы), объединяются в единое целое — класс, а доступ к внутреннему состоянию ограничивается (`private`/`protected`). Взаимодействие с объектом идёт только через публичный интерфейс, что позволяет:
- защитить инварианты объекта от некорректных изменений извне;
- скрыть детали реализации;
- менять реализацию, не ломая код пользователя.
2. Для чего используются ключевые слова public и private?
private - доступ к этим элементам класса разрешён только внутри этого же класса.
public - доступ к этим элементам класса разрешён ото всюду.
наследование потом подробнее изучу.

4. Существуют ли ограничения на использование public и private в классе? А в структуре?
Ограничений нет. И в классе, и в структуре можно многократно и в любом порядке использовать `public`, `private` и `protected`. Единственное различие между `class` и `struct` — доступ по умолчанию: в классе — `private`, в структуре — `public`. Если этот default явно переопределить, класс и структура по возможностям полностью эквивалентны.
```cpp
class A
{
	private:
		int x;
	public:
		int y = 2;
	private:
	...
};
```

7. Разрешается ли объявлять указатель на объект? А указатель на класс?
#### Указатель на объект
```cpp
#include <iostream>
class example
{
public:
	void doSomething()
	{
		std::cout << 10 << std::endl;
	}
};
int main()
{
    example object;
    example* ptr = &object;

    return 0;

```
Указатель на класс объявить не получится, потому что это ТИП, а не объект с адресом памяти.
5. Допускается ли передавать объекты в качестве параметров, и какими способами? А возвращать как результат?
Объекты в качестве параметров допускается передавать. Это можно сделать по значению, по ссылке, по указателю, по константной ссылке и по константному указателю

#### Передача объекта по значению (копирование)
```cpp
#include <vector>
class Point
{
private:
    int x_ = 0;
    int y_ = 0;
    std::vector<int> payload_ = std::vector<int>(100'000'000, 67); // ~381 MB
public:
    int getX() { return x_; }
    int getY() { return y_; }
    void setX(int x) { x_ = x; }
    void setY(int y) { y_ = y; }
};
void objectHandler_Value(Point obj)
{
    obj.setX(1);
    obj.setY(2);
}
int main()
{
    Point pointObject;
    objectHandler_Value(pointObject);
    return 0;
}
```
![[Pasted image 20260920131623.png]]
1. `Point pointObject;` в `main` — вектор выделяет **~381 МиБ** в куче. RSS растёт до ~381 МБ.
2. Вызов `objectHandler_Value(pointObject)`:
    - создаётся **локальная копия** `obj`,
    - у неё свой `payload_`, а значит **ещё ~381 МБ** выделяется в куче,
    - содержимое копируется (`memcpy` 400 МБ).
3. Пик памяти: **~762 МБ**.
4. При выходе из функции копия разрушается — её 381 МБ освобождаются.
#### По ссылке
```cpp
#include <vector>
class Point
{
private:
    int x_ = 0;
    int y_ = 0;
    std::vector<int> payload_ = std::vector<int>(100'000'000, 67); // ~381 MB
public:
    int getX() { return x_; }
    int getY() { return y_; }
    void setX(int x) { x_ = x; }
    void setY(int y) { y_ = y; }
};
void objectHandler_Value(Point& obj)	// <========== добавили &
{
    obj.setX(1);
    obj.setY(2);
}
int main()
{
    Point pointObject;
    objectHandler_Value(pointObject);
    return 0;
}
```
![[Pasted image 20260920132254.png]]
	1. `Point pointObject;` — тот же вектор на **~381 МБ**.
	2. Вызов `objectHandler_Value(pointObject)`:	    
	    - **никакой копии не создаётся**,
	    - `obj` — это просто псевдоним `pointObject` (по сути указатель под капотом, 8 байт в стеке),
	    - `setX`/`setY` работают с оригиналом.
	3. Пик памяти: **~381 МБ**.

### Основные способы

| Синтаксис            | Копия?     | Можно менять оригинал?     | Может быть «ничего»?           | Владение        | Когда использовать                               |
| -------------------- | ---------- | -------------------------- | ------------------------------ | --------------- | ------------------------------------------------ |
| `T obj`              | да, полная | нет (меняется копия)       | нет                            | копия у функции | только мелкие типы (`int`, `double`, пара полей) |
| `T& obj`             | нет        | да                         | нет                            | у вызывающего   | функция должна изменить объект                   |
| `const T& obj`       | нет        | нет                        | нет                            | у вызывающего   | **по умолчанию** для чтения больших объектов     |
| `T* obj`             | нет        | да                         | да (`nullptr`)                 | у вызывающего   | объект может отсутствовать; менять нужно         |
| `const T* obj`       | нет        | нет                        | да (`nullptr`)                 | у вызывающего   | объект может отсутствовать; только чтение        |
| `T* const obj`       | нет        | да                         | нет (сам указатель фиксирован) | у вызывающего   | адрес не должен меняться внутри функции          |
| `const T* const obj` | нет        | нет                        | нет                            | у вызывающего   | адрес фиксирован, объект только для чтения       |
| `T*& obj`            | нет        | да (и объект, и указатель) | да                             | у вызывающего   | функция должна переприсвоить указатель           |
| `T** obj`            | нет        | да                         | да                             | у вызывающего   | то же в стиле C                                  |
| `T&& obj`            | нет        | да                         | нет                            | перемещение     | принимать только временные объекты               |
| `T&& obj` в шаблоне  | нет        | да                         | нет                            | перемещение     | forwarding reference, perfect forwarding         |


6. Как называется использование объекта одного класса в качестве поля другого класса?
Агрегация или композиция
Агрегация - внешний объект не владеет вложенным, а только ссылается на него. Вложенный объект создаётся и уничтожается где-то ещё, независимо от внешнего.
Композиция - это включение объекта одного класса в другой по значению, при котором внешний объект владеет вложенным: вложенный создаётся вместе с внешним (или в его конструкторе) и разрушается вместе с ним. Внешний объект не может существовать без вложенного.
6. Что такое композиция?
Композиция - это включение объекта одного класса в другой по значению, при котором внешний объект владеет вложенным: вложенный создаётся вместе с внешним (или в его конструкторе) и разрушается вместе с ним. Внешний объект не может существовать без вложенного.
7. Что такое метод? Как вызывается метод?
Метод - это функция класса.
В отличие от свободной функции, метод:
- имеет доступ к `private` и `protected` полям своего класса;
- получает **неявный указатель `this`** на объект, для которого вызван (кроме статических методов);
- может быть виртуальным, константным, статическим.

Метод можно вызвать так:
через объект:                       object.method()
через указатель на объект: objectPrt->method()
через ссылку на объект:      objectRef.method()
через имя класса:                 Class::method()    если в классе метод объявлен static T method()

9. Как определить метод непосредственно внутри класса? А вне класса? Чем эти определения отличаются?
#### внутри класса
Метод пишется прямо в теле класса:
```cpp
class Point
{
private:
    int x_ = 0;
    int y_ = 0;
public:
    int getX() const { return x_; }
    void setX(int x) { x_ = x; }
    void print() const
    {
        std::cout << "(" << x_ << ", " << y_ << ")\n";
    }
};
```

#### вне класса
```cpp
class Point
{
private:
    int x_ = 0;
    int y_ = 0;
public:
    int  getX() const;          // только объявление
    void setX(int x);           // только объявление
    void print() const;         // только объявление
};
// ---- реализации например в "Point.cpp"----
int Point::getX() const
{
    return x_;
}
void Point::setX(int x)
{
    x_ = x;
}
void Point::print() const
{
    std::cout << "(" << x_ << ", " << y_ << ")\n";
}
```

11. Что обозначается ключевым словом this?
`this` — это неявный указатель на объект, для которого вызван нестатический метод. Компилятор автоматически передаёт его как скрытый первый параметр. Через `this` метод получает доступ к полям и другим методам именно этого объекта.

12. Зачем нужны константные методы? Чем отличается определение константного метода от обычного?
Если объект объявлен константным: const Class object, то у object можно вызывать только константные методы, НЕ константные нельзя
```cpp
#include <iostream>
class A
{
public:
	int x = 1;
	int method() 	{	return x;	}
	int constMethod() const	{	return x;	}
};
int main()
{
	const A a;
	std::cout << a.method() << std::endl;      // нельзя, ошибка
	std::cout << a.constMethod() << std::endl; // можно
    return 0;
}
```
