37. Дайте определение конструктора. Каково назначение конструктора? Перечислите отличия конструктора от метода.
Конструктор - это метод, который вызывается автоматически при создании объекта и служит для его инициализации: установки начальных значений полей, выделения ресурсов.
Отличия от метода:
- ничего не возвращает
- имеет название как название класса
- не может быть static, const, virtual

Генерируется только если в классе нет ни одного объявленного конструктора.
```cpp
class A { int x_; };       // компилятор сделает A() {} — но x_ не инициализирован
A a;                        // вызовется этот неявный конструктор
```

39. Может ли конструктор быть приватным? Какие последствия влечет за собой объявление конструктора приватным?
Да, может быть приватным. В таком случае конструктор можно вызвать только в самом классе.
Это применяется в паттерне Singleton, у которого при первом вызове инстанцируется объект класса, а при всех последующих вызовах передаётся ссылка на этот единственный объект класса. Так же используется в utility-классах, в которых только static методы и отсутствуют объекты. Ещё есть фабрики, но их я пока не понял.
